# Proyecto Secano · IDECAM

Visor web institucional para consulta y seguimiento del Proyecto Secano.

## Criterio de publicación

- El mapa principal consume únicamente capas verificadas/publicadas en IDECAM.
- El inventario crudo entregado se utiliza para indicadores de avance y control, no como cartografía validada.
- `SUPLETA = 1` se interpreta como **Supletorio**.
- `SUPLETA = 0` se interpreta como **Con título**.

## Corte de datos analizado

- 500 parcelas únicas en el universo espacial consolidado.
- 205 parcelas verificadas/subidas.
- 295 parcelas en revisión/trabajo.
- 205 supletorias.
- 257 con título.
- 38 sin dato de condición.

Aplicación construida con Vite + MapLibre GL JS.
